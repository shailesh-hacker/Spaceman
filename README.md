# Spaceman 🚀

A retro-style 2D arcade survival game built using **Python** and **Pygame**. Control a spaceman navigating through a hazardous asteroid field, avoid incoming comets, and try to achieve the highest score!

---

## 🎮 Features

- **Dynamic Obstacles:** Face randomized comets falling at varying speeds and horizontal positions.
- **Fluid Controls:** Move in all four directions (Up, Down, Left, Right) to dodge obstacles.
- **Audio Controls:** Immersive background space music with in-game mute and unmute controls.
- **Persistent High Scores:** Track and save your personal best score locally across game sessions.
- **Clean Arcade UI:** Simplified retro menus and score display.

---

## 🕹️ Controls

| Action | Key |
| :--- | :--- |
| **Start Game** | `Spacebar` |
| **Move Up / Down** | `↑` / `↓` Arrow Keys |
| **Move Left / Right** | `←` / `→` Arrow Keys |
| **Mute Background Music** | `X` |
| **Unmute Background Music** | `Z` |
| **Quit Game (Game Over Screen)**| `Spacebar` |

## 🛠️ Installation & Setup

Ensure you have Python 3 installed on your system.

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/shailesh-hacker/Spaceman.git
   cd Spaceman
   ```

2. **Install Dependencies:**
   Install `pygame` via pip:
   ```bash
   pip install pygame
   ```

3. **Run the Game:**
   ```bash
   python spaceman.py
   ```

## 📂 Project Structure

- `spaceman.py` — Main game logic and loop.
- `space.mp3` — Background soundtrack.
- `player.png` — Spaceman sprite.
- `comet.png` — Obstacle sprite.
- `back.jpg` — Space background.
- `high_score.txt` — File containing the persistent local high score.
